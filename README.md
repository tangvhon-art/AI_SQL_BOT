# AI 问数系统

自然语言问数平台：用自然语言提问，系统自动完成 SQL 生成、知识检索、权限控制、图表生成，让业务人员直接「问」出数据。

## 功能介绍

### AI 问数
- **自然语言转 SQL**：输入业务问题，自动生成可执行 SQL，返回文字说明 + 图表，SQL 可展开/复制/下载
- **多查询拆解**：复杂问题自动拆分为多个子查询，用户确认后并行执行，结果合并为仪表盘
- **生成中断**：生成过程中可随时点击停止按钮终止，所有后续步骤立即停止
- **文件问答**：对话中上传文档（txt/md/pdf/docx），基于文档内容问答并返回引用来源
- **历史会话**：对话落库保存，可从历史记录继续追问

### 洞察分析
- **六步向导**：描述分析目的 → 选择数据源 → AI 生成分析草案 → 确认配置（编辑标题/图表类型/启用状态）→ 预览报告 → 保存模板
- **AI 生成草案**：根据分析目的自动拆解为多个分析项，支持选择模型
- **报告预览**：基于确认配置生成真实数据预览，每项独立展示图表
- **模板管理**：保存分析配置为模板，列表页支持搜索、生成报告、编辑、删除
- **AI 生成报告标题**：格式为「洞察报告-{主题}相关报告-{日期}」

### 报告中心
- **报告列表**：查看所有已生成报告，支持搜索
- **AI 解读**：对报告数据进行智能解读，支持选择 Prompt 模板
- **Prompt 管理**：管理 AI 解读提示词，支持增删改查、设置默认

### 数据管理
- **数据源管理**：数据源 CRUD、连接测试、Schema 采集（表名/字段注释/主键/外键）
- **Schema 详情**：查看表与字段、补录注释、表关联搜索、手动添加/删除关联关系
- **知识库（RAG）**：FAQ（问题/答案/SQL 示例）+ 文档上传，智能切片向量化，问数时检索增强，越问越准

### 权限与审计
- **三级权限**：整表限制（注入 1=2 拦截）、字段级限制（受限字段脱敏为 ****）、行级限制（按规则注入过滤条件）
- **权限规则**：角色全局 + 用户级，可查并集 / 不可查并集 / 黑名单优先
- **组织管理**：角色、用户组、用户三级管理，菜单权限随角色下发
- **审计日志**：问数全链路留痕（权限注入类型、SQL、行数、耗时）

### 结果复用与调度
- **保存查询**：问数结果保存为查询，支持 `{param}` 参数化
- **定时任务**：cron 表达式定时生成数据与图表快照，失败重试，查看运行历史

### 系统能力
- **模型配置**：OpenAI 兼容协议（DeepSeek / 通义 / Kimi / 本地 vLLM / Ollama 等），支持 SQL 模型和 Embedding 模型分别配置
- **评测中心**：评测用例管理、批次执行、指标报告（意图正确率/表命中率/SQL 正确率等）
- **缓存管理**：SQL 生成缓存 / 结果缓存统计与清理
- **系统配置**：成本门槛、限流超时、样例值采集等能力参数在线调整

## 启动方式

### 一键启动（推荐）

```bash
./start.sh
```

同时启动后端（端口 **8001**）与前端（端口 **3001**），日志输出到 `logs/backend.log`、`logs/frontend.log`；Ctrl+C 优雅停止。

自定义端口：`BACKEND_PORT=9001 FRONTEND_PORT=5173 ./start.sh`

### 手动启动

```bash
# 后端（端口 8001）
cd backend
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
cp .env.example .env        # 按需修改 LLM_API_KEY 等
.venv/bin/uvicorn app.main:app --port 8001

# 前端（端口 3001，已代理 /api → :8001）
cd frontend
npm install
npm run dev
```

### 访问入口

- 前端：http://localhost:3001 ，默认账号 `admin / admin123`
- API 文档：http://localhost:8001/docs

## 使用流程

1. **数据源管理** → 新建数据源 → 测试连接 → 采集 Schema
2. **模型配置** → 配置 LLM（不配置则进入演示模式）
3. **知识库** → 新建 FAQ / 上传文档，提升问数准确率
4. **权限控制** → 配置角色/用户的可查/不可查规则
5. **AI 问数** → 输入业务问题，获取文字说明 + 图表；复杂问题自动拆解多查询
6. **洞察分析** → 描述分析目的 → AI 生成草案 → 确认配置 → 预览报告 → 保存模板或生成报告
7. **报告中心** → 查看报告，使用 AI 解读功能分析数据
8. **结果复用** → 保存查询为参数化模板，创建定时任务自动生成快照
